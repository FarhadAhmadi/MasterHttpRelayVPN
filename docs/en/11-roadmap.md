# 11) v1 Roadmap and Next Versions

## v1 (Current)

- Full local proxy stack
- Telegram mode + auth + telemetry dashboard
- Telegram diagnostics command
- Smart profiles (`strict_tg`, `balanced`, `max_speed`)
- Optional JSONL telemetry persistence
- Route rules file support + self-healing runtime
- Structured documentation set

## v1.x Candidate Improvements

- Automatic best-route profile switching (dynamic, no restart)
- Per-country/provider rule packs
- Browser-specific CA trust deep checks by profile
- More dashboard visual analytics

## v2 Direction (Proposed)

- Provider abstraction layer for multiple relay backends
- richer policy engine per app/domain
- packaged desktop release workflow
- larger automated test matrix
