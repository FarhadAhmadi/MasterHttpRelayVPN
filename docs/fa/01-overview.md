# ۱) معرفی

MasterHttpRelayVPN یک پروکسی محلی است که ترافیک برنامه‌ها/مرورگر را دریافت کرده و در صورت نیاز از مسیر Google Apps Script رله می‌کند.

خلاصه مسیر:

1. کلاینت به پروکسی محلی وصل می‌شود.
2. در HTTPS، امکان MITM محلی با گواهی CA وجود دارد.
3. درخواست از مسیر رله ارسال می‌شود.
4. پاسخ به کلاینت برگردانده می‌شود.

## هدف پروژه

- بهبود اتصال در شبکه‌های محدود.
- یک نقطه پروکسی محلی برای برنامه‌ها.
- مشاهده‌پذیری با داشبورد، API و متریک‌ها.

## نکات مهم v1

- HTTP + SOCKS5
- رله Apps Script
- حالت سازگاری Telegram Desktop
- داشبورد داخلی + API + Prometheus
