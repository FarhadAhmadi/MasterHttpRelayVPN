# ۱۱) نقشه راه v1 و نسخه‌های بعدی

## v1 (فعلی)

- پروکسی کامل محلی
- حالت Telegram + auth + داشبورد
- دستور Telegram Diagnose
- پروفایل‌های هوشمند (`strict_tg`, `balanced`, `max_speed`)
- ثبت اختیاری JSONL برای تله‌متری
- پشتیبانی فایل route rules + self-heal
- مجموعه مستندات ساختاریافته

## بهبودهای v1.x

- سوئیچ پروفایل هوشمند پویا (بدون ری‌استارت)
- rule pack آماده برای اپراتورها/کشورها
- بررسی عمیق‌تر trust مرورگرها
- تحلیل‌های تصویری بیشتر داشبورد

## مسیر v2 (پیشنهادی)

- abstraction برای چند backend رله
- policy engine پیشرفته per-app/per-domain
- بسته‌بندی دسکتاپ آسان‌تر
- تست خودکار گسترده‌تر
